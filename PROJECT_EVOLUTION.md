# Project Evolution

## Original project
Built during the 3rd year of engineering as a basic Python voice assistant.

Original capabilities:
- Google speech recognition
- pyttsx3 text-to-speech
- browser opening
- time lookup
- joke generation
- local music playback

## Re-engineering goals
The project is intentionally rebuilt rather than represented as if the original college implementation already contained modern AI architecture.

The upgraded version introduces:
- modular OOP architecture
- tool abstraction
- deterministic intent routing
- optional LLM fallback
- bounded conversation context
- structured logging
- latency instrumentation
- unit tests
- environment configuration
- Docker packaging

This distinction keeps the project technically honest while showing engineering growth.
